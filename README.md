Project Earth LAN ist ein virtuelles Layer-2-Netzwerk auf Basis von ZeroTier One, das speziell für PC-Spieler entwickelt wurde, um ältere und aktuelle LAN- oder Koop-Spiele unkompliziert über das Internet zu spielen. Die Verbindung erfolgt direkt als Peer-to-Peer (P2P)-Verbindung, wodurch kein manuelles Portforwarding (Portfreigaben) im Router erforderlich ist und sich alle Mitspieler im selben virtuellen Raum fühlen.

Für die Administration und Nutzung dient der Project Earth LAN Manager als All-in-One-Tool.
